# Prompt2Patch – Projector Dashboard
Static web app, no install or build step.

Run:  python3 -m http.server 8000   (inside this folder) -> open http://localhost:8000
      or `npx serve .`, or just double-click index.html. Use Chrome or Edge.

Keys: Space start/pause, R reset, P music, M mute, Up/Down volume, F fullscreen, I image mode, H hide/show panel.
Image modes: Fit (whole poster, natural shape), 4:5, Stretch (whole poster fills screen, distorts), Crop (fills screen, cuts edges).
Poster: replace assets/poster.jpg (the poster part only, ~74.6% of the full poster height; the rest is the timer area).
